## Learn Git on the same graphs

[Learn Git](https://initialcommit.com/learn/git) at initialcommit.com has sixteen guided levels played on git-sim graphs. Each one shows you a command, asks you to type it, and plays what it did, on a repo you build from scratch.

Then come back here, open the live graph on one of your own repos, and watch your real commands do the same thing.

More: the [git-sim page](https://initialcommit.com/tools/git-sim), the [README](https://github.com/initialcommit-com/git-sim#readme) with every command and option, and the [visual Git command reference](https://initialcommit.com/learn/git/visual-command-reference).
