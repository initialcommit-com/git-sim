## Learn Git on the same graphs

[Learn Git](https://initialcommit.com/learn/git) at initialcommit.com is
sixteen guided levels played on git-sim graphs: each one shows a command, asks
you to type it, and plays what it did, on a repository you build from nothing.

Then come back here, open the live graph on a repository of your own, and watch
your real commands do the same thing.

More: the [git-sim page](https://initialcommit.com/tools/git-sim), the
[README](https://github.com/initialcommit-com/git-sim#readme) with every
command and option, and the
[visual Git command reference](https://initialcommit.com/learn/git/visual-command-reference).
